# Wine Quality App

Приложение загружает заранее обученный pipeline логистической регрессии и позволяет:

- оценить одно вино по 12 признакам;
- посмотреть метрики и ROC/PR-кривые при выбранном пороге;
- получить пакетные предсказания для CSV;
- изучить коэффициенты модели после масштабирования признаков.

## Запуск

Проверенная версия интерпретатора — Python 3.12.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

В загружаемом CSV должны присутствовать все 12 признаков из `test.csv`, столбец `target` не нужен.

## Кэширование

Модель загружается через `st.cache_resource`, потому что это тяжёлый разделяемый объект, который должен создаваться один раз на весь сервер. Таблица и рассчитанные вероятности кэшируются через `st.cache_data`: они являются данными, которые можно безопасно переиспользовать между перезапусками скрипта. Без декоратора `joblib.load` выполнялся бы заново при каждом действии пользователя, в том числе при движении слайдера порога.

## Деплой

Для Streamlit Community Cloud нужно загрузить содержимое этой папки в GitHub-репозиторий, выбрать файл `app.py` и версию Python 3.12. Все пути строятся относительно папки приложения, поэтому рабочая директория сервера не влияет на запуск.
